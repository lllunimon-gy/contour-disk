# 口径先于图表

元数据层在 Objective-C 中使用 lstat，最后一个路径分量不会被解引用。
普通文件再查询 NSURLTotalFileAllocatedSizeKey，无法获取时保留 st_blocks * 512。
Swift 只消费结构化字段，不在上层重复访问相同属性。

统计排除目录本身的占用与符号链接文件，包含目录里的普通文件。
identity 是 device + inode，只用于单次扫描的硬链接去重；不能作为跨机器永久标识。
克隆文件可能具有不同 inode 却共享物理块，所以不能用该去重方式推导实际可释放空间。

取消是协作式：每个文件处理前检查，已进入的系统调用不能强制打断。
进度按每 128 个目录项及扫描结束触发；目录总量未知，不提供虚假的完成百分比。
单个元数据错误被收集，根目录不存在或无法枚举则抛错。

差异只允许比较同根、无失败、未取消的两个快照。这仍不是文件系统一致性快照，
调用方需要停止写入或接受扫描窗口内的偏差。排序稳定，硬链接计入哪个路径取决于枚举顺序；
总量稳定，但硬链接跨业务目录时，归属不应作为计费依据。
